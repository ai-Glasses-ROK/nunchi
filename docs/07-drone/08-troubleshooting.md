## 연결

| 증상 | 원인 · 해결 |
|---|---|
| USB를 꽂아도 반응이 없음 | OTG를 지원하는 폰인지, 충전 전용이 아닌 데이터 케이블인지 확인하고, USB 권한 창에서 허용하세요. 앱은 픽스호크(CDC-ACM)와 FTDI·CP210x·CH340 칩의 텔레메트리 라디오를 알아요 |
| 텔레메트리 라디오가 '신호 기다리는 중'에서 멈춤 | 보드레이트 57600(TELEM1 기본), 두 라디오의 주파수·설정이 같은지. 연결되면 초록 불이 깜빡이지 않고 계속 켜져요 |
| 프레임 수와 함께 체크섬 오류도 늘어남 | 보드레이트가 안 맞아요 → 57600과 115200을 바꿔 보세요 |
| 블루투스 연결 실패 | 폰 설정에서 먼저 페어링(PIN 1234 또는 0000), 모듈 TX↔픽스호크 RX 엇갈림, `SERIAL2_PROTOCOL=2`·`SERIAL2_BAUD=57` |
| Wi-Fi UDP로 아무것도 안 옴 | 같은 와이파이인지, 포트 14550, 컴퓨터 방화벽, 다른 지상국 프로그램(Mission Planner·QGroundControl)이 14550을 잡고 있지 않은지 |
| 에뮬레이터에서 UDP | `adb emu redir add udp:14550:14550`이 필요해요. iOS 시뮬레이터와 동시에 쓰면 맥의 14550이 겹치니 하나씩 시험하세요 |
| `port out of range:-1` | 예전 빌드의 버그예요 → 최신으로 다시 빌드하세요 |
| '신호 끊김'이 자꾸 뜸 | 5초 동안 하트비트가 없을 때예요. 라디오 거리·안테나, USB 케이블 접촉을 보세요 |
| 맥에서 시리얼 포트를 못 찾음 | `ls /dev/cu.usbmodem*`(픽스호크), `/dev/cu.usbserial*`·`wchusbserial*`(라디오). 다른 프로그램이 포트를 잡고 있으면 닫으세요 |
| 아이폰에서 USB·블루투스 연결 | 앱에서 쓸 수 없어요 → 와이파이 모듈이나 `scripts/mavlink_bridge.py` 중계(Wi-Fi UDP) |

## 상태 표시

| 증상 | 원인 · 해결 |
|---|---|
| HUD에 배터리 값이 없음 | 전원 모듈 설정 파라미터 `BATT_MONITOR`를 켜세요 |
| GPS '위치 못 잡음' | 실내·창가에서는 잘 안 잡혀요. 하늘이 트인 곳에서 몇 분 기다리세요 |
| PreArm 경고가 안 보임 | 30초마다 오므로 연결 뒤 최대 30초 기다리세요. 시동이 걸리면 비워져요 |
| 해결한 PreArm이 계속 보임 | 앱은 가장 최근 묶음만 보여 줘요. 다음 묶음(30초 뒤)에 그 경고가 없으면 빠지고, 40초 넘게 새 묶음이 없으면 모두 사라져요 |
| 모드 이름이 숫자로 나옴 | 표에 없는 펌웨어나 모드예요 (ArduPilot Copter·Plane·Rover와 PX4 모드를 알아요) |

## 영상

| 증상 | 원인 · 해결 |
|---|---|
| 영상이 안 나옴 · 지글거림 · 흑백 | [실습 9 §7 — 영상이 안 나올 때](../04-practice/09-fpv-video.md#7-영상이-안-나올-때) |
| 맥 카메라 중계가 "10초 동안 영상이 안 와요" | 명령을 실행한 앱에 카메라 권한이 있어야 해요(시스템 설정 → 개인정보 보호 및 보안 → 카메라). 다른 앱 안에 든 터미널(IDE·AI 도우미 등)은 권한 창을 못 띄우고 멈출 수 있으니 맥 기본 '터미널' 앱에서 실행하세요 |
| 앱에 MJPEG가 안 들어옴 | 주소 끝 `/stream.mjpg`, 에뮬레이터는 `10.0.2.2`, 실제 폰은 컴퓨터 IP + 중계에 `--host 0.0.0.0` |
| PAL 수신기라 중계에 영상이 안 옴 | `--input-fps 25` |

## 분석

| 증상 | 원인 · 해결 |
|---|---|
| "카메라 화면이 아직 없어요" | 카메라를 켜고 첫 화면이 온 뒤 분석하세요 |
| "서버에 연결할 수 없습니다" | 앱 설정의 허브 주소·토큰, 허브를 `--host 0.0.0.0`으로 띄웠는지, 폰과 같은 네트워크인지 |
| 답이 기체 상태와 상관없는 이야기 | 드론 질문으로 판별되지 않으면 경고를 검색어에 붙이지 않아요 → "왜 시동이 안 걸려?"처럼 드론 낱말을 넣어 물어보세요 → [드론 질문 판별](04-status-then-retrieve.md#5-언제-붙이나--드론-질문-판별) |
| 폰 Gemma 4가 안 돎 | `models/` 폴더에 `.litertlm` 파일이 있는지, 램(8GB 이상 권장). GPU가 안 되면 CPU로 다시 시도해서 느려요 |
| 분석이 느림 | 허브 모델을 줄이거나(e4b → e2b), 자동 분석을 끄세요 |
