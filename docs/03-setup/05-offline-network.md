# 인터넷 없는 와이파이 만들기 (허브 모드)

허브 모드는 **인터넷은 없어도 되지만, 폰과 허브가 같은 와이파이**에 있어야 해요.

## 1. 방법 비교

| 방법 | 난이도 | 비용 | 추천 상황 |
|---|---|---|---|
| **여행용 미니 공유기** (USB 전원) | 쉬움 | 2~5만 원 | 현장·차량·캠핑. 가장 추천 |
| 집 공유기에서 인터넷 선만 빼기 | 매우 쉬움 | 0원 | 집·사무실 실험 |
| 안드로이드 폰 핫스팟 (유심 없이) | 보통 | 0원 | 기기마다 비행기 모드와 함께 안 될 수 있음 → 직접 확인 |
| 노트북 핫스팟 | 보통 | 0원 | OS·기종마다 다름 |

> 아이폰의 개인용 핫스팟은 셀룰러 데이터를 나누는 기능이라, 유심 없는 공기계·비행기 모드에선 쓸 수 없어요.

## 2. 여행용 공유기 설정 (예시)

1. 공유기 USB 전원 연결 → 기본 와이파이 이름/비밀번호(공유기 뒷면)로 접속
2. 관리 페이지에서 와이파이 이름·비밀번호를 바꾸고, **WAN(인터넷) 연결 없음** 그대로 사용
3. 허브 컴퓨터와 공기계를 같은 와이파이에 연결
4. 공유기 관리 페이지의 'DHCP 고정 할당'으로 허브 컴퓨터 IP를 고정하면 앱 설정을 다시 안 바꿔도 돼요.

## 3. 허브 주소 찾기

```bash
nunchi doctor
```

`이 컴퓨터 주소: 192.168.8.10 · Bonjour 이름: my-mac.local` 처럼 나옵니다.

- 앱 설정의 허브 주소: `http://192.168.8.10:8765`
- 아이폰은 Bonjour 이름도 됩니다: `http://my-mac.local:8765` (IP가 바뀌어도 그대로)

## 4. 방화벽

- **맥**: 처음 `nunchi serve --host 0.0.0.0` 를 실행할 때 "들어오는 연결 허용?" → 허용. 놓쳤다면 시스템 설정 → 네트워크 → 방화벽 → 옵션에서 파이썬 허용.
- **윈도우**: "Windows 보안 경고"에서 '개인 네트워크' 허용.
- **리눅스(ufw)**:

```bash
sudo ufw allow 8765/tcp
```

## 5. 보안

- 같은 와이파이의 누구나 허브에 접속할 수 있으니 **토큰**을 쓰세요: `nunchi serve --host 0.0.0.0 --token <비밀번호>`
- 앱·웹 설정에 같은 토큰을 넣으면 됩니다. 웹 페이지 자체는 열리지만 API는 토큰 없이는 401로 거절돼요.
- 공유기 와이파이에도 비밀번호(WPA2/WPA3)를 거세요.

## 6. 연결 시험

폰 브라우저로 `http://<허브IP>:8765` 를 열어 웹 클라이언트가 뜨면 네트워크는 정상입니다. 토큰을 썼다면 ⚙︎ 설정에 입력하세요.
