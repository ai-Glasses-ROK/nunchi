# 재난문자 방해 없이 쓰기 (공기계 전용)

> ⚠️ **이 설정은 안경 전용 공기계에만** 하세요. 몸에 지니는 메인 폰은 반드시 재난문자를 받게 둡니다. 원리는 [오프라인과 재난문자](../02-concepts/02-offline-and-alerts.md).

## 1. 설정 순서

1. (인터넷 될 때) [오프라인 꾸러미](02-offline-bundle.md) 체크리스트 끝내기 — 앱 등록·권한·모델·음성 데이터
2. 공기계에서 **비행기 모드 켜기** → 셀룰러가 꺼져 재난문자(셀 방송)를 받지 않음
3. **블루투스 다시 켜기** → 안경 연결
4. **와이파이 다시 켜기**
   - 허브 모드: 인터넷 없는 와이파이(오프라인 공유기)에 연결
   - 단독 모드: 공유기 연결은 필요 없지만, 안경 카메라 고화질(Wi-Fi) 전송을 쓰려면 켜 두기

대부분의 폰은 다음에 비행기 모드를 켤 때도 블루투스·와이파이 상태를 기억해요.

## 2. 왜 알림 끄기만으로는 부족한가

| 방법 | 위급재난문자 | 긴급재난문자 | 안전안내문자 |
|---|---|---|---|
| 알림 설정에서 끄기 | ✗ 못 끔 | ○ | ○ |
| 유심 빼기 | 기기에 따라 수신될 수 있음 | | |
| **비행기 모드** | ○ 수신 안 됨 | ○ | ○ |

알림 설정 위치(보조 수단, OS 버전마다 이름이 조금씩 달라요):
- 아이폰: 설정 → 알림 → 맨 아래 정부 경보(재난문자) 항목
- 갤럭시: 설정 → 안전 및 긴급 → 무선 긴급 알림
- 설정 앱 검색창에 "재난" 또는 "긴급 알림"으로 찾는 게 가장 빠릅니다.

## 3. 동작 확인

1. 비행기 모드 + 블루투스 + 와이파이 아이콘이 함께 보이는지
2. Nunchi 앱 상단: 안경 "연결됨", 허브 "연결됨"
3. 음성 질문 → 안경 스피커로 답이 나오는지

## 4. 문제가 생기면

| 증상 | 해결 |
|---|---|
| 비행기 모드 후 안경이 끊김 | 블루투스를 다시 켜고 Meta AI 앱을 한 번 열기 |
| Meta AI 앱이 "인터넷 필요"라고 함 | 와이파이를 잠깐 인터넷에 붙여 동기화 후 다시 오프라인 |
| 카메라 권한을 다시 물음 | '한 번만 허용'을 골랐던 경우 → 인터넷 될 때 '항상 허용'으로 |
| 허브 연결 안 됨 | 같은 와이파이인지, 허브가 `--host 0.0.0.0` 인지, 로컬 네트워크 권한(iOS) |
