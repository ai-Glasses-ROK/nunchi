# 공기계 준비

## 1. 어떤 폰이 좋나

| 용도 | 아이폰 | 안드로이드 |
|---|---|---|
| 허브 모드(폰은 중계만) | iOS 17.2+ (DAT 최소 사양) | Android 12+ (Nunchi 앱 최소 사양) |
| 단독 모드(폰에서 LLM) | iOS 26+ & Apple Intelligence 기기(iPhone 15 Pro 이상) | 램 8GB+ (직접 통합 필요, [단독 모드](../04-practice/07-standalone-phone.md)) |
| 상시 켜 두는 허브폰 | 백그라운드 제약이 있음 | 포그라운드 서비스로 상시 실행 쉬움 |

> 유심은 없어도 됩니다. 단, 유심 없는 폰도 재난문자를 받는 경우가 있어요 → [비행기 모드](04-airplane-mode.md).

## 2. Meta AI 앱과 안경

1. Meta AI 앱 설치 → Meta 계정 로그인
2. 안경 페어링 (앱 안내 따라 하기) → 펌웨어 업데이트
3. **개발자 모드 켜기**: Meta AI 앱 → 설정 → 내 안경 → 개발자 모드
   - 개발자 모드에서는 앱 등록 때 Meta Developer Center 앱 ID 없이 테스트할 수 있어요.

> 안경은 보통 폰 한 대에만 연결됩니다. 메인 폰과 번갈아 쓰면 매번 다시 연결해야 해서, 안경 전용 공기계를 두는 이유가 여기 있어요.

## 3. Nunchi 앱 설치

- iOS: 맥에서 Xcode로 빌드해 설치 → [iOS 앱](../04-practice/05-ios-app.md)
- Android: Android Studio로 빌드해 설치 → [Android 앱](../04-practice/06-android-app.md)

## 4. 앱에서 연결하기 (인터넷 필요, 처음 한 번)

1. Nunchi 앱 → 설정 → **Meta AI 앱과 연결** → Meta AI 앱으로 넘어가 승인 → 자동으로 돌아옴
2. 첫 사진 질문 때 카메라 권한 요청 → Meta AI 앱에서 **항상 허용**
3. 허브 주소(`http://<허브IP>:8765`)·토큰 입력 → **연결 테스트**
4. (단독 모드를 쓸 거면) **허브에서 지식베이스 받기**

## 5. 권한 체크 (설정 앱)

| 권한 | 아이폰 | 안드로이드 | 없으면 |
|---|---|---|---|
| 블루투스 | 설정 → Nunchi → 블루투스 | 근처 기기 | 안경 연결 불가 |
| 마이크 | 설정 → Nunchi → 마이크 | 마이크 | 녹음 불가 |
| 로컬 네트워크 | 설정 → Nunchi → 로컬 네트워크 | (해당 없음) | 허브 접속·안경 Wi-Fi 영상 불가 |
| 음성 인식 | 설정 → Nunchi → 음성 인식 | — | 단독 모드 받아쓰기 불가 |

## 6. 발열·배터리 관리

- 충전기에 꽂아 두고 쓸 땐 **케이스를 벗기고** 통풍되는 곳에
- 화면 밝기 최저, 자동 잠금은 길게(앱이 화면 켜짐 상태일 때 가장 안정적)
- 단독 모드는 배터리를 빨리 씁니다. 장시간이면 허브 모드가 유리
