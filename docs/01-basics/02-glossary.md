# 용어 사전

> 분야별로 묶었어요. 각 용어는 **한 줄 뜻 → 쉬운 비유 → 이 프로젝트에서는** 순서입니다.

## AI · 언어 모델

| 용어 | 뜻 | 비유 / 이 프로젝트에서 |
|---|---|---|
| **AI 모델** | 데이터로 학습한 계산 덩어리(숫자 파일) | 경험으로 배운 직원의 머릿속. Ollama로 내려받는 수 GB짜리 파일 |
| **LLM** (대형 언어 모델) | 다음에 올 글자를 예측하며 글을 쓰는 모델 | 문장 이어 쓰기 달인. Gemma 4, gpt-oss 등 |
| **로컬 LLM** | 내 컴퓨터/폰에서 도는 LLM | 회사에 출근 안 하고 우리 집에 사는 직원 |
| **파라미터** | 모델 안의 숫자 개수 (예: 2B = 20억 개) | 뇌세포 연결 수. 클수록 똑똑하지만 무겁고 느림 |
| **E2B / E4B** | Gemma 4의 '실효 20억/40억 파라미터' 소형 모델 | 폰·노트북용 경량 두뇌. 이 레포의 기본값 |
| **토큰** | 모델이 글을 자르는 단위 (한국어 1토큰 ≈ 1~2글자) | 레고 블록. 길이·속도·비용의 단위 |
| **컨텍스트 창** | 한 번에 읽을 수 있는 토큰 수 | 책상 크기. 넘치면 앞부분을 잊음 |
| **양자화** | 숫자 정밀도를 낮춰 모델을 가볍게 하는 기술 (예: 4bit) | 고화질 사진을 JPEG로 압축. 조금 흐려지지만 훨씬 가벼움 |
| **추론(inference)** | 학습된 모델로 답을 만드는 과정 | 실제로 일하는 시간 |
| **사고(thinking) 모드** | 답 전에 속으로 풀이를 길게 쓰는 기능 | 연습장에 풀고 답 쓰기. 수학엔 좋지만 느림 |
| **환각(hallucination)** | 그럴듯한 거짓을 지어내는 현상 | 모르는데 아는 척. RAG로 줄입니다 |
| **온도(temperature)** | 답의 무작위성 정도 (0=항상 같은 답) | 즉흥성 다이얼. 비서 용도는 낮게(0.3) |
| **프롬프트** | 모델에게 주는 지시문·질문 | 업무 지시서 |
| **시스템 프롬프트** | 대화 전체에 적용되는 기본 규칙 | 직원 행동 강령 ("짧게, 마크다운 금지") |
| **멀티모달** | 글 외에 이미지·소리도 입력받는 능력 | 눈과 귀가 달린 모델. Gemma 4는 글+사진+소리 |
| **비전 모델** | 사진을 이해하는 모델 | 사진 질문("이게 뭐야?")에 사용 |
| **MLX** | 애플 실리콘용 머신러닝 엔진 | 맥에서 더 빠름. `gemma4:e4b-mlx` 처럼 표시 |
| **GGUF** | llama.cpp 계열의 모델 파일 형식 | 폰·PC 어디서나 쓰는 범용 포장 |
| **Ollama** | 로컬 LLM을 쉽게 내려받고 돌리는 프로그램 | 모델 앱스토어 + 실행기. 이 레포의 기본 엔진 |
| **Foundation Models** | iOS 26+ 의 기기 내장 LLM 프레임워크 | 아이폰에 원래 들어 있는 두뇌 (Apple Intelligence 기기) |

## 검색 · RAG

| 용어 | 뜻 | 비유 / 이 프로젝트에서 |
|---|---|---|
| **RAG** (검색 증강 생성) | 관련 문서를 먼저 찾아서 LLM에게 함께 주는 방식 | 오픈북 시험. 외워서가 아니라 찾아보고 답함 |
| **지식베이스(KB)** | RAG가 검색할 내 문서 모음 | 사내 자료실. `nunchi ingest` 로 채움 |
| **청크(조각)** | 문서를 검색하기 좋게 자른 단위 (기본 600자) | 책을 한 쪽씩 오려 둔 카드 |
| **청킹** | 문서를 조각으로 나누는 일 | 카드 만들기. 제목·문단을 지키며 자름 |
| **오버랩** | 앞 조각 끝을 다음 조각 앞에 겹쳐 붙임 | 카드 사이 문맥 끊김 방지 |
| **임베딩** | 글을 의미가 담긴 숫자 벡터로 바꾼 것 | 글의 '좌표'. 뜻이 비슷하면 가까움 |
| **벡터** | 숫자 여러 개의 묶음 (bge-m3는 1024개) | 지도 위 위치 |
| **코사인 유사도** | 두 벡터의 방향이 얼마나 같은지 (-1~1) | 두 화살표의 각도 |
| **BM25** | 단어 겹침으로 점수를 매기는 고전 검색 | 색인 찾기. 고유명사·숫자에 강함 |
| **2-gram(바이그램)** | 글자를 두 개씩 잘라 비교 | '회의실은' → 회의/의실/실은. 한국어 조사 문제 해결 |
| **하이브리드 검색** | 키워드(BM25)와 의미(임베딩) 검색을 합침 | 두 탐정의 의견 종합 |
| **RRF** | 순위만 보고 여러 검색 결과를 합치는 방법 | 점수 단위가 달라도 공정한 투표 |
| **top-k** | 검색 결과 중 상위 몇 개를 쓸지 | 참고할 카드 장수 (기본 4) |
| **캡션→검색** | 사진을 먼저 한 줄로 묘사해 검색어에 더함 | "이게 뭐야?"도 문서를 찾게 해 주는 기법 |
| **번호 조회** | 질문의 "5번·3단계·12쪽"과 같은 번호가 붙은 제목의 절을 검색 대신 바로 가져옴 | 책의 목차로 바로 펼치기. 수능 실험에서 검색 적중 100% |
| **절 확장 (small-to-big)** | 작은 조각으로 찾고, 답할 땐 그 조각이 속한 절 전체를 줌 | 색인 카드로 찾고 책은 그 장을 통째로 펼침 |
| **NFKC 정규화** | 모양만 다른 같은 글자를 하나로 맞춤 (①→1, ｆｕｌｌ→full) | 검색에는 좋지만 글 자체를 바꿈(선택지 ⑤→5). 그래서 Nunchi는 검색 토큰화에서만 쓰고, 저장·LLM에는 원문 |
| **OCR** | 이미지 속 글자를 텍스트로 옮기기 | 수능 수학: 비전 모델이 문제를 LaTeX로 옮기고 다른 모델이 풂 |
| **SQLite** | 파일 하나로 된 데이터베이스 | 이 레포의 지식베이스 저장소 (`index.sqlite3`) |

## 음성

| 용어 | 뜻 | 비유 / 이 프로젝트에서 |
|---|---|---|
| **STT** (음성 인식) | 말소리 → 글자 | 받아쓰기. Gemma 4가 직접 함 |
| **TTS** (음성 합성) | 글자 → 말소리 | 낭독. 폰 TTS 또는 lfm3-audio |
| **샘플레이트** | 1초에 소리를 몇 번 재는지 (Hz) | 동영상의 초당 프레임 수 |
| **8kHz / 16kHz** | 초당 8,000번 / 16,000번 측정 | 안경 마이크(HFP)는 8kHz라 'ㅅ/ㅊ' 같은 소리가 뭉개짐 |
| **나이퀴스트 주파수** | 샘플레이트의 절반 = 담을 수 있는 최고음 | 8kHz면 4kHz까지만 기록 |
| **VAD** | 말소리 구간 감지 | 무음 자르기 |
| **CER** | 문자 오류율 (틀린 글자 비율) | 한국어 STT 성적표. 낮을수록 좋음 |
| **WAV / PCM** | 압축 안 한 소리 파일 / 원시 샘플 | 허브가 받는 기본 형식 |

## 안경 · 연결

| 용어 | 뜻 | 비유 / 이 프로젝트에서 |
|---|---|---|
| **Meta AI 앱** | 안경을 폰과 연결·관리하는 공식 앱 | 안경의 관리 사무소. 지우면 안 됨 |
| **DAT** (Device Access Toolkit) | 앱이 안경 카메라·마이크에 접근하게 해 주는 Meta SDK | 관리 사무소 출입증. v1.0.1, 개발자 프리뷰 |
| **SDK** | 개발 도구 모음 | 공구함 |
| **개발자 모드** | Meta AI 앱에서 테스트 앱 연결을 허용하는 설정 | 실험실 출입 허가 |
| **등록(Registration)** | 내 앱을 Meta AI 앱에 연결하는 1회 절차 (인터넷 필요) | 출입증 발급 |
| **세션(DeviceSession)** | 앱과 안경 사이의 연결 단위 | 통화 연결. 한 안경에 동시에 하나만 |
| **MockDeviceKit** | 실물 없이 가상 안경을 만드는 테스트 도구 | 모의 훈련용 마네킹 |
| **블루투스 LE** | 저전력 블루투스. 발견·제어용 | 무전기의 호출 채널 |
| **블루투스 클래식** | 대역이 넓은 블루투스. 카메라 영상용 | 화물 트럭 |
| **HFP** | 블루투스 '통화' 규격. 마이크+스피커, 8kHz | 전화 음질 |
| **A2DP** | 블루투스 '음악' 규격. 스피커만, 고음질 | 음악 음질. 답변은 이걸로 들려줌 |
| **SCO** | HFP가 소리를 실어 나르는 연결 (안드로이드 용어) | 통화 채널 |
| **공기계** | 유심 없이 쓰는 남는 폰 | 안경 전용 허브폰 |

## 네트워크 · 개발

| 용어 | 뜻 | 비유 / 이 프로젝트에서 |
|---|---|---|
| **허브** | 무거운 계산을 하는 컴퓨터 | 두뇌. `nunchi serve` |
| **서버 / 클라이언트** | 요청을 받는 쪽 / 보내는 쪽 | 식당 주방 / 손님 |
| **API** | 프로그램끼리 대화하는 약속된 창구 | 주문서 양식. `/v1/voice` 등 |
| **HTTP / HTTPS** | 웹 통신 규약 / 암호화된 버전 | 편지 / 봉인된 편지 |
| **SSE** | 서버가 답을 조금씩 흘려보내는 방식 | 실시간 자막. 첫 문장부터 바로 읽기 시작 |
| **IP 주소** | 네트워크 안의 기기 주소 (예: 192.168.0.10) | 집 주소 |
| **포트** | 한 기기 안의 창구 번호 (기본 8765) | 아파트 호수 |
| **localhost / 127.0.0.1** | '이 컴퓨터 자신' | 우리 집 |
| **0.0.0.0** | '모든 네트워크에서 접속 허용' | 대문 열기. 토큰과 함께 쓰세요 |
| **Bonjour(mDNS)** | IP 대신 `내맥.local` 이름으로 찾기 | 문패 |
| **토큰** (인증) | 접속 비밀번호 같은 문자열 (`NUNCHI_TOKEN`) | 출입 카드. AI 토큰과는 다른 말 |
| **환경변수** | 프로그램 설정을 바깥에서 넣는 값 | 출근 전 메모 |
| **가상환경(venv)** | 프로젝트별 파이썬 공간 | 프로젝트 전용 공구함 |
| **CBS** (셀 방송) | 기지국이 구역 전체 폰에 보내는 방송 | 재난문자의 전송 방식 |
| **비행기 모드** | 셀룰러 등 무선을 끄는 모드 (블루투스·와이파이는 다시 켤 수 있음) | 재난문자 차단의 확실한 방법 |
