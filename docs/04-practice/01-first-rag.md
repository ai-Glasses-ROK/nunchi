## 1. 예제 문서 넣기

`examples/knowledge/` 에는 실습용 **가상의** 문서 3개가 있어요 (캠핑장 안내, 발전기 매뉴얼, 허브 설명서).

```bash
nunchi ingest ../examples/knowledge
```

```
지식베이스: /Users/me/nunchi/index.sqlite3
임베딩: bge-m3:latest
  ✓ HG-2000-발전기-점검절차.md → 조각 7개
  ✓ 솔바람-캠핑장-이용안내.md → 조각 9개
  ✓ 오프라인-허브-사용설명서.md → 조각 6개

완료 (1.3초): 파일 3개 중 추가 3 · 갱신 0 · 변경없음 0 · 실패 0 · 새 조각 22개
```

- 같은 명령을 다시 실행하면 바뀐 파일만 다시 색인해요(`변경없음`).
- 폴더에서 지운 파일을 색인에서도 지우려면 `--prune`.

## 2. 묻기

```bash
nunchi ask "토요일에 가면 몇 시에 들어갈 수 있어?"
```

```
🔎 검색 (hybrid, 56.2ms)
  [1] 솔바람 캠핑장 이용 안내 > 매너 타임 의미 0.49 키워드 0.8
  [2] 솔바람 캠핑장 이용 안내 > 물과 샤워 의미 0.47 키워드 0.8
  [3] 솔바람 캠핑장 이용 안내 > 입실과 퇴실 의미 0.57 키워드 0.6
  [4] 솔바람 캠핑장 이용 안내 > 전기 사용 의미 0.36 키워드 3.0
💬 주말이나 공휴일 전날에는 입실 시간이 오후 3시부터이니 참고해 주세요. 다른 요일에는 오후 2시부터 입실이 가능합니다.
⏱️  retrieval 56.2ms · first_token 4209ms · llm 4561ms · total 4617ms
```

읽는 법:
- 문서엔 "토요일"이라는 말이 없고 "주말과 공휴일 전날"만 있어요. 그래도 **의미 검색**이 '입실과 퇴실' 조각을 찾아 정답을 냈습니다.
- 첫 질문의 `first_token 4209ms` 는 모델을 메모리에 올리는 시간이 포함된 값이에요. 두 번째부터는 0.3초 안팎입니다.


## 4. 내 문서 넣기

```bash
nunchi ingest ~/Documents/내매뉴얼
```

- 지원 형식: `.md .txt .pdf .docx .html .csv`
- 스캔 PDF(그림)·수식 위주 PDF는 글자가 안 뽑힐 수 있어요. 수능 수학이 그랬습니다 → [평가](../05-applications/03-evaluation.md)
- 마크다운이면 `#` 제목을 잘 달수록 검색이 좋아져요(맥락 헤더).

들어 있는 문서 확인·삭제:

```bash
nunchi kb
```

```bash
nunchi kb --remove 내문서.md
```

## 5. 답 스타일 바꾸기

```bash
nunchi ask "발전기 시동 방법 알려줘" --style text
```

`text` 는 화면용(목록·인용 번호 허용), 기본 `voice` 는 귀로 듣는 짧은 답.

## 6. 문서에 없는 질문

```bash
nunchi ask "캠핑장 와이파이 비밀번호 알려줘"
```

```
💬 죄송하지만, 제공된 문서에는 캠핑장 와이파이 비밀번호에 대한 정보가 없습니다.
```

지어내지 않아요. 문서 밖 질문엔 아예 답하지 않게 하려면 `NUNCHI_STRICT_RAG=true`.

## 7. 연구용: 내 질문 세트로 정확도·지연 재기

```bash
nunchi bench --file ../examples/eval/questions.jsonl -o bench.jsonl
```

질문 파일 형식(JSONL):

```json
{"q": "캠핑장 체크인은 몇 시부터야?", "expect": ["2시|14시"], "source": "솔바람-캠핑장-이용안내.md"}
```

`expect` 의 `|` 는 "둘 중 하나만 있어도 정답". → [평가와 실험 결과](../05-applications/03-evaluation.md)
