## 허브

| 메시지·증상 | 원인 | 해결 |
|---|---|---|
| `Ollama에 연결할 수 없어요` | Ollama가 꺼짐 | Ollama 앱 실행 또는 `ollama serve` |
| `모델 'X'이 없어요. 먼저 실행: ollama pull X` | 모델 미설치 | 안내된 명령 실행 |
| `임베딩 생략(키워드 검색은 가능)` | 임베딩 모델 없음/오류 | `ollama pull bge-m3` 후 `nunchi ingest … --reembed` |
| `질의 임베딩 차원(…)과 색인 차원(…)이 달라요` | 임베딩 모델을 바꿈 | `nunchi ingest <폴더> --reembed` |
| `이 서버는 /v1/audio/transcriptions 를 지원하지 않아요` | 오래된 Ollama | Ollama 업데이트 |
| 음성 인식이 이상하게 잘림 | (구버전) 무음 자르기 기준 문제 | 최신 코드 사용, 또는 `NUNCHI_AUDIO_PREPROCESS=false` 로 비교 |
| `WAV가 아닌 오디오는 ffmpeg가 있어야…` | m4a/webm 업로드 | `brew install ffmpeg` 또는 WAV로 보내기 |
| `HEIC 사진은 지원하지 않아요` | 맥이 아닌 허브에서 HEIC | JPEG로 보내기 (앱·웹은 자동) |
| `address already in use` | 포트 8765 사용 중 | `nunchi serve --port 8766` |
| 첫 질문만 매우 느림 | 모델 로딩 | 정상. 두 번째부터 빨라짐 (예열·keep_alive) |

## 네트워크

| 증상 | 해결 |
|---|---|
| 폰에서 허브 접속 안 됨 | 같은 와이파이? 허브를 `--host 0.0.0.0`? 방화벽 허용? → [오프라인 와이파이](../03-setup/05-offline-network.md) |
| `401 토큰이 맞지 않아요` | 앱·웹 설정의 토큰을 허브와 같게 |
| 아이폰만 안 됨 | 설정 → Nunchi → **로컬 네트워크** 켜기 |
| 폰 브라우저에서 마이크 버튼이 꺼져 있음 | HTTPS 필요 → `nunchi serve --https` |

## 안경·앱

| 증상 | 해결 |
|---|---|
| "안경 마이크를 찾지 못했어요" | 안경 블루투스 연결 확인, 또는 설정에서 폰 마이크로 |
| 등록 버튼이 "사용 불가" | Meta AI 앱 설치·로그인, **개발자 모드** 켜기 |
| 등록이 진행되지 않음 | 등록은 **인터넷 필수** → 비행기 모드 해제 후 |
| 카메라 권한을 계속 물음 | '한 번만 허용' → Meta AI 앱에서 '항상 허용'으로 |
| "No eligible device" | 안경을 켜고 다리를 펴고(착용), Meta AI 앱에서 연결 확인 |
| (직접 만든 앱) 안경은 '연결됨'인데 사진이 "연결 시간 초과" | 세션 상태 스트림을 `start()` **뒤에** 만들면 빠르게 지나간 `.started`를 놓침 → `start()` 전에 구독 ([iOS 앱 문서](../04-practice/05-ios-app.md#7-개발-중-알게-된-것)) |
| 펌웨어 업데이트 후 사진이 안 찍힘 | 안경 재부팅 (펌웨어 v128 알려진 이슈) |
| 안경 배터리 10% 미만에서 설치·연결 실패 | 충전 후 재시도 (알려진 이슈) |
| 아이폰 17 + iOS 26에서 통화(HFP) 소리가 안 남 | Meta 알려진 이슈 → iOS 27 이상으로 업데이트 |
| 안경을 벗었다 쓰면 버튼 입력이 멈춤 | 알려진 이슈 → 앱이 Inputs 기능을 다시 붙여야 함 |
| 세션이 '일시정지'에서 안 돌아옴 | 안경을 다시 착용. 실험 기능은 재개 후 다시 시작 필요(알려진 이슈) |
| iOS: `Wearables.configure()` Internal error | 코드 서명 없이 빌드한 경우 → Xcode 기본 서명으로 |
| 답이 통화 음질로 들림 | 녹음 후 재생 경로 전환이 안 됨 → 앱 재시작, 블루투스 재연결 |

## 수능 실험 스크립트

| 증상 | 해결 |
|---|---|
| 수학 문항 이미지가 전체 쪽으로 나옴 | macOS `sips` 의 `--cropOffset` X=0 무시 버그 → 최신 `prepare.py`(X=1부터) |
| `ValueError: invalid literal for int(): '⑤'` | 파이썬은 `'⑤'.isdigit()` 이 True → 최신 `run_eval.py` |
