# 안전 · 개인정보 · 법

> 이 레포는 **연구·학습 목적**입니다. 아래 원칙을 지켜 주세요.

## 1. 재난 안전
- 재난문자 차단(비행기 모드)은 **안경 전용 공기계에만**. 몸에 지니는 메인 폰은 항상 재난문자를 받게 둡니다.
- 응급 상황에서는 안경 비서보다 **119**가 먼저입니다.
- 안경 비서의 답은 참고용이에요. 의료·안전·법률 판단은 전문가에게 확인하세요.

## 2. 촬영과 타인의 개인정보
- 스마트 안경 카메라는 **주변 사람이 촬영 사실을 알아채기 어렵습니다.** 사람을 찍을 땐 동의를 구하세요.
- 안경의 촬영 표시등을 가리지 마세요.
- 공공장소라도 특정인을 몰래 촬영·녹음·공유하면 법적 문제가 될 수 있어요(개인정보 보호법, 통신비밀보호법 등 — 대화 녹음은 당사자 여부에 따라 달라짐).
- 탈의실·화장실·의료기관 등 촬영 금지 장소에서는 안경을 벗거나 카메라를 쓰지 마세요.

## 3. 시험과 부정행위
- 이 레포의 수능 실험은 **이미 끝난 기출문제**로 로컬 모델의 능력을 재는 연구입니다.
- **실제 시험장에서 스마트 안경·AI 기기를 쓰는 것은 부정행위**이며 처벌 대상입니다. 절대 그런 용도로 쓰지 마세요.

## 4. 저작권
- 수능 문제지는 한국교육과정평가원 저작물이고, 국어·영어 지문에는 원저작자의 권리도 있어요. 그래서 **문제 원문·PDF를 레포에 넣지 않았고**, 평가원에서 직접 받아 실험하는 스크립트만 제공합니다. 정답 번호(사실 정보)만 `research/csat/answers_2026.json` 에 담았어요.
- 내 지식베이스에 넣는 문서도 저작권·회사 보안 규정을 지키세요.

## 5. 데이터가 어디로 가나 (Nunchi 기준)

| 데이터 | 허브 모드 | 단독 모드 |
|---|---|---|
| 음성·사진·질문 | 공기계 → 같은 와이파이의 내 허브 | 공기계 안 |
| 지식베이스 | 허브 `~/nunchi/index.sqlite3` | 폰 앱 문서 폴더 `kb.json` |
| 대화 기억 | 허브 메모리(30분 후 삭제), 디스크 저장 안 함 | 저장 안 함 |
| 외부 전송 | 없음 | 없음 |

- 허브 `/v1/kb` 응답은 허브 컴퓨터의 전체 파일 경로를 숨깁니다.
- 앱의 Meta DAT 분석 데이터 전송은 꺼 두었어요(Info.plist `MWDAT > Analytics > OptOut = true`).
- **Meta AI 앱 자체**의 데이터 처리(안경 연결, 등록, 권한)는 Meta의 정책을 따릅니다. Nunchi가 통제할 수 없는 부분이에요.

## 6. 네트워크 보안
- 허브는 기본적으로 이 컴퓨터에서만 열려요(`127.0.0.1`). 폰 접속을 위해 `0.0.0.0` 으로 열 땐 **토큰**을 거세요.
- 공유기 와이파이엔 WPA2/WPA3 비밀번호.
- 안드로이드 앱은 로컬 허브용으로 평문 HTTP를 허용합니다. 민감한 환경이면 `nunchi serve --https`.
