# 오프라인과 재난문자

## 1. 재난문자는 어떻게 오나: 셀 방송(CBS)

재난문자는 일반 문자(SMS)와 달리, 기지국이 **그 구역 안의 모든 폰에 한꺼번에 방송**하는 셀 방송(Cell Broadcast Service) 방식이에요.

- 전화번호와 상관없이, 기지국 신호를 받는 폰이면 받습니다.
- 그래서 **유심이 없는 공기계도 받는 경우가 있어요.** (기기·통신 상태에 따라 다름)
- 반대로 **셀룰러 무선 자체가 꺼지면** 받을 수 없습니다 → 비행기 모드.

## 2. 단계별 재난문자와 끌 수 있는지

| 종류 | 예 | 알림 설정으로 끄기 |
|---|---|---|
| 위급재난문자 | 공습, 화생방 등 | **불가** |
| 긴급재난문자 | 지진, 대형 재난 | 가능 |
| 안전안내문자 | 폭염, 실종자 등 | 가능 |

그래서 공기계에서 경보음을 확실히 막는 방법은 **비행기 모드**뿐입니다.

## 3. 비행기 모드에서도 되는 것

| 기능 | 비행기 모드에서 | 메모 |
|---|---|---|
| 셀룰러(통화·문자·데이터·재난문자) | ✗ | 의도한 것 |
| 블루투스 | ○ 다시 켤 수 있음 | 안경 연결 |
| 와이파이 | ○ 다시 켤 수 있음 | 허브 연결, 안경 Wi-Fi 영상 |
| GPS | 기기마다 다름 | |

대부분의 폰은 한 번 블루투스·와이파이를 다시 켜 두면 다음 비행기 모드 때도 기억해요.

## 4. 안전 원칙 (꼭 지켜 주세요)

1. **재난문자 차단은 안경 전용 공기계에만.** 몸에 지니는 메인 폰은 반드시 재난문자를 받게 둡니다.
2. 혼자 산·바다·외진 현장에 갈 땐, 공기계 대신 메인 폰의 경보가 울리는지 출발 전에 확인하세요.
3. 공기계는 충전기에 꽂아 오래 켜 두면 뜨거워져요. 케이스를 벗기고 통풍되는 곳에.
4. 응급 상황이라면 안경 비서보다 119가 먼저입니다. Nunchi의 음성 프롬프트도 응급 질문엔 119 신고를 먼저 말하도록 되어 있어요.

## 5. '인터넷 없음'과 '네트워크 없음'은 다르다

- **허브 모드**: 인터넷은 없지만 **로컬 네트워크(같은 와이파이)** 는 필요합니다. 공유기를 인터넷 선 없이 켜 두면 돼요. → [인터넷 없는 와이파이 만들기](../03-setup/05-offline-network.md)
- **단독 모드**: 네트워크가 전혀 없어도 됩니다.

## 6. 처음 한 번은 인터넷이 필요한 것들

오프라인으로 가기 전에, 인터넷이 될 때 끝내야 하는 일이 있어요.

- Meta AI 앱 설치·로그인·안경 페어링
- **DAT 앱 등록**(Registration) — 인터넷 필수
- 카메라 권한 **'항상 허용'** (한 번만 허용을 고르면 다음에 또 물어봄)
- 모델 내려받기(Ollama), 파이썬 부품 설치, 폰 TTS 한국어 음성 데이터

빠짐없는 목록은 [인터넷이 될 때 미리 챙길 것](../03-setup/02-offline-bundle.md)에 있습니다.
