## 1. 실물 안경 검증 (우선순위 높음)

| 과제 | 확인할 것 |
|---|---|
| 오프라인 지속성 | 등록·'항상 허용' 후 비행기 모드에서 DAT 세션·카메라가 며칠간 유지되는지 |
| HFP 8kHz 실측 | 합성 음성이 아닌 **실제 사람 목소리·실제 HFP**에서의 CER (우리 수치는 `say` 합성 음성 기준) |
| 16kHz 경로 | DAT 카메라 스트림 오디오(실험 기능, 16kHz PCM)로 녹음했을 때 CER 개선 폭 |
| 허브 모드 + Wi-Fi 카메라 | 안경 Wi-Fi 영상 전송 중 폰이 허브 와이파이와 동시에 통신 가능한지(폰이 안경 핫스팟에 붙는 구조) |
| 기기별 차이 | 레이밴 메타 / 오클리 / 디스플레이 모델별 사진 화질·지연 |
| iPhone 17 + iOS 26 HFP 무음 이슈 | Meta 알려진 이슈. iOS 27에서 해결되는지 |
