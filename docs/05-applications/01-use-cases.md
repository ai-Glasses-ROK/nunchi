# 활용 시나리오

> 각 시나리오는 **넣을 문서 → 묻는 말 → 설정 팁** 순서입니다. 모두 인터넷 없이 동작해요.

## 1. 현장 작업 보조 (Field Assist)
- **문서**: 장비 매뉴얼, 점검 체크리스트, 고장 코드표 (예: `examples/knowledge/HG-2000-발전기-점검절차.md`)
- **말**: "다음 단계 뭐야?", "E2 코드가 떴어", 📷 계기판 사진 + "이거 왜 이래?"
- **팁**: 매뉴얼은 절차를 `##` 단위로 나누고 번호 목록 유지. 손이 바쁘니 '답 읽기 = 폰'과 블루투스 버튼 트리거 추천.

## 2. 아웃도어·캠핑·재난 대비
- **문서**: 시설 이용 규칙, 응급처치 요령(공신력 있는 자료), 지도 메모, 비상 연락 체계
- **말**: "체크아웃 몇 시야?", "뱀에 물리면 어떻게 해?"
- **팁**: 산속은 와이파이도 없으니 **단독 모드**. 응급 질문엔 119가 먼저라는 규칙이 프롬프트에 들어 있어요. 메인 폰의 재난문자는 꼭 켜 두기.

## 3. 여행 (데이터 로밍 없이)
- **문서**: 여행 일정, 숙소 정보, 자주 쓰는 현지어 표현 메모
- **말**: "호텔 체크인 몇 시?", 📷 메뉴판 + "이거 뭐야?"
- **팁**: 사진 질문은 허브 모드에서 → 노트북 + 여행용 공유기를 숙소에 두고, 낮에는 단독 모드.

## 4. 공부·시험 대비 (연구용)
- **문서**: 정리 노트, 교재 요약, 기출 해설(저작권 확인)
- **말**: "작용·반작용 예시 들어 줘", "이 문제 어떤 개념이야?"
- **팁**: 화면으로 볼 땐 `style=text`. 문제집·기출처럼 번호가 있는 자료는 문항마다 `## 5번` 같은 제목을 달아 넣으면 "5번 문제 설명해 줘"가 그 문항으로 바로 갑니다(번호 조회). 우리 수능 실험 결과는 [평가](03-evaluation.md).
- ⚠️ 실제 시험장에서 AI 안경·기기 사용은 **부정행위**입니다.

## 5. 접근성 (읽기 보조)
- **문서**: 가전 설명서, 약 복용 안내(의사·약사 안내문), 생활 정보
- **말**: 📷 + "이거 읽어 줘", "이 버튼은 뭐야?"
- **팁**: 시각 보조로 쓸 땐 답을 조금 길게(`NUNCHI_MAX_TOKENS` 상향), `style=text`보다 `voice`가 듣기 좋음. **약·의료 정보는 참고용**이며 전문가 확인이 필요해요.

## 6. 사내 규정·업무 안내 (보안 환경)
- **문서**: 사내 규정, 업무 매뉴얼, FAQ (외부 반출 금지 문서)
- **말**: "출장비 정산 기한이 언제야?"
- **팁**: 허브를 사내망에만 두고 `NUNCHI_TOKEN` 필수. 문서가 클라우드로 나가지 않는 게 이 구조의 가장 큰 장점.

## 7. 요리·생활
- **문서**: 레시피 모음, 가전 사용법
- **말**: "다음 순서 뭐야?", "오븐 몇 도였지?"
- **팁**: 손에 반죽이 묻어 있을 때 안경이 진가를 발휘. 후속 질문("그다음은?")을 이해합니다.

## 문서 준비 요령 (공통)

| 하면 좋은 것 | 이유 |
|---|---|
| 제목(`#`, `##`)을 주제별로 | 맥락 헤더로 검색 정확도 상승 |
| 한 항목 = 한 문단 | 조각 경계가 깔끔 |
| 숫자·고유명사는 그대로 | 키워드 검색이 잘 잡음 |
| 표는 CSV로 따로 | '열이름: 값' 문장으로 변환되어 검색됨 |
| 스캔 PDF는 글자로 변환 후 | 그림 PDF는 글자가 안 뽑힘 |
